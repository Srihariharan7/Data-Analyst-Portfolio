# Data Analyst Portfolio Website

## Preview locally
1. Extract this folder.
2. Open `index.html` in Chrome or another browser.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository, for example `data-analyst-portfolio`.
3. Upload all contents of this folder (make sure `index.html` is at the repository root).
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/data-analyst-portfolio/`.

## Personalise before publishing
Open `index.html` and replace:
- `Hello! I’m an aspiring Data Analyst` with your preferred introduction.
- The LinkedIn button URL `https://www.linkedin.com/` with your actual LinkedIn profile URL.
- Add your email address and GitHub profile link in the contact section if you want recruiters to contact you directly.

The project files are included under `assets/projects/` and the project cards link to them for download.
